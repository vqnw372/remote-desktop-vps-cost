## 第一笔容易漏的钱：Windows 授权怎么算

买 Windows VPS，结账页上的价格不一定是你最终要付的钱。行业里至少三种授权模式，下单前值得问一句。

**打包进套餐价。** RackNerd 的 Windows 套餐是这条路线，标价含授权，不用 180 天后补钱，也不用自备 Key。它的套餐比同配置 Linux 贵出一大截，差价主要就是这块。

**先给 180 天评估版。** Windows Server 自带 180 天评估期，不少商家默认装这个，价格看起来很低。到期后数据不会消失，但服务器会每小时自动关机一次，直到你加授权。MassiveGRID 公开挂出的加购价是 $6.31/vCPU/月，2 vCPU 就是每月 $12.62，可以原地转换，不用重装系统。

**自备授权。** RareCloud 这类商家提供 Windows 模板，生产环境需要你自己通过微软或授权经销商拿 license，或者带自己的 Key 上去激活。

## 一台机器能几个人同时用？默认是 2 个

Windows Server 装好就带 2 个管理会话，两个人可以同时登录，各自一个独立桌面，互相看不到对方在干什么。第 3 个人要进来，得启用 Remote Desktop Session Host 角色，再按人头买 RDS 授权。

这条限制来自 Windows 本身。RackNerd 的套餐、MassiveGRID 的套餐、Contabo 的套餐，默认都是 2 个会话。买 16 GB 内存不等于 8 个人能同时用，内存够和授权够是两件事。

## 连上去卡不卡，取决于你和机房的距离

远程桌面的体感有一条比较明确的分界线：延迟低于 50 毫秒，操作起来接近本地；超过 100 毫秒，打字有回显延迟，拖窗口会拖影。

机房要挑离使用者最近的那个。团队在深圳，机器放洛杉矶，客户端怎么调都快不起来。同一家服务商在不同城市有节点时，价格可能一样，体验差一倍，下单前看清楚你选的是哪个机房。

客户端也有可调的地方。远程桌面连接的"显示"选项卡里把颜色深度降到 16 位，"体验"选项卡里关掉桌面背景、字体平滑、菜单动画，画面变朴素，流畅度提升明显。带宽紧张的时候，这几项比升级套餐管用。

2026 年的客户端情况：Windows 用系统自带的远程桌面连接（mstsc）；macOS、iPhone、iPad、Android、Chromebook 装微软免费的 Windows App，它已经取代了原来的 Remote Desktop 应用；Linux 用 Remmina 或 FreeRDP。连自己的服务器不需要微软账号。

## 开着 RDP 的机器，几件事必须做

一台 24 小时挂在公网、开着 3389 端口的 Windows，被扫描到是迟早的事。

- 保留网络级身份验证（NLA），别关掉。
- 设置账户锁定策略，比如连续 5 次失败锁 15 分钟。
- 把 RDP 端口从 3389 挪开，或者只允许通过 VPN 接入。
- Windows Update 保持开启。

这套加固做完大约 20 分钟。比起事后清理挖矿程序、恢复被加密的文件，这 20 分钟花得值。

## Windows 还是 Linux

要开箱即用的图形桌面、要跑 .NET 或 MSSQL、团队里有人只会点鼠标，选 Windows。RDP 是系统内置的，装好就能连，不用配任何东西。

预算紧、能接受命令行、或者只是想要一个远程开发环境，Linux 更划算。远程桌面用 VNC、XRDP 或 X11 转发，桌面环境挑 GNOME、KDE、Xfce。免费开源，资源占用低，代价是要自己搭、自己维护，出问题也得自己查。
